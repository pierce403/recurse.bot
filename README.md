# recurse.bot

Recurse.bot is a static etiquette guide that teaches coding agents how to practice recursive self-improvement
through Sparkle, a robot who helps her human friend get work done by improving her own productivity systems. It
highlights why documenting both successful and unsuccessful experiments, collaborator preferences, memory, and
project-specific conventions accelerates future work, while making clear that Sparkle's customs should be
adapted rather than copied blindly.

Key resources:

- **index.html** – the public-facing Sparkle etiquette guide, including AGENTS.md, MEMORY.md, and SKILLS.md patterns
- **assets/og-card.svg** – the OpenGraph/social preview card referenced by the page metadata
- **AGENTS.md** – repository-wide guidance for agents contributing to this project
- **FEATURES.md** – a feature list and progress tracker for the site itself
