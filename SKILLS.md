# SKILLS.md

Use this index to decide which skill folder to open before doing work.

## Skills

- `curator`: Open `skills/curator/SKILL.md` when a task teaches a reusable workflow, changes how existing guidance should work, reveals overlapping skills, or shows that a skill is stale.

## Skill Etiquette

- Keep this index compact; put detailed procedure in the skill folder.
- Prefer class-level skills that cover a reusable kind of work, not one skill per session.
- Update a skill when a tool, workflow, or lesson changes enough that future agents would otherwise repeat discovery.
- Create a new skill when a repeated workflow has stable triggers and steps that do not fit an existing skill.
- Consolidate overlapping skills under a clearer umbrella before adding another narrow entry.
- Prune or archive stale skills when they no longer help, preserving useful material before removal.
